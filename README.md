# 2026-2 C++ 복습 저장소 (화34·목34)

수업 시간에 `save()` 함수로 기록한 **`2026 C++ 화34모34.txt`** 로그를 기준으로,
실제로 **수업을 들은 날짜별 폴더**에 소스코드를 나눠 정리했습니다.

## 폴더 읽는 법

- `2026-09-08/` 처럼 날짜 폴더 = 그날 수업
- 안의 파일 `03_1200_소스.cpp` = 그날 **3번째로 저장한 코드, 12시 00분에 저장**
  → 번호 순서대로 보면 수업 중 코드가 어떻게 바뀌었는지 따라갈 수 있습니다.
- `04_1311/` 처럼 폴더로 된 것 = 같은 순간에 여러 파일(`소스.cpp`, `Xtring.h`, `Xtring.cpp`, `save.h` …)을 함께 저장한 것
- 완전히 똑같은 내용을 다시 저장한 것은 한 번만 남겼습니다.
- `*_로컬본_*` = 로그에는 없고 PC에만 남아 있던 파일 (`11_1249_수업중_로컬본` = 수업 도중 상태라 컴파일되지 않음)
- `save.h` / `save.cpp` 는 `2026-09-08/03_1200/` 에 있습니다 (거의 모든 코드가 include)
